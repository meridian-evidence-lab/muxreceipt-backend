# Roadmap

## 0.2: connected local development
- Browser dashboard, persisted API audits, deterministic engine integration.
- Contract proposal generation and authorization-tested Soroban contracts.
- Shared API specification, local run instructions and contributor backlog.

## Next release
- Official SDK-based XDR normalization and provenance-verified registry reads.
- Wallet-signed testnet deployment and invocation, with explicit network configuration.
- Review privacy, storage TTL/archival behavior, key rotation, access control and resource bounds.
- Expand automated browser/accessibility tests and perform an independent security review.

No mainnet deployment or custody functionality is included.
